Privacy Policy

Rclone Lubuntu Sync

Rclone Lubuntu Sync is a personal-use configuration of the open-source rclone software for synchronizing files between my Lubuntu computer and my own Google Drive account.

Data Access

The application requests Google Drive access to list, read, create, modify, and delete files as necessary for synchronization.

Data Storage

Files are synchronized between my local computer and Google Drive. OAuth credentials are stored locally in the rclone configuration.

Data Sharing

This application is intended for my personal use. It does not operate a separate server that collects or sells Google user data.

Data Retention

Files remain in my local storage and Google Drive until I modify or delete them. OAuth access can be revoked through Google Account settings.

Contact

For questions, contact the application owner using the support email shown on the Google OAuth consent screen.
